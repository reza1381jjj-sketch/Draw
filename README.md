# تبدیل عکس به طرح خطی سیاه و سفید

یک صفحه‌ی وب ساده (بدون نیاز به سرور یا نصب چیزی) که عکس ورودی رو با الگوریتم تشخیص لبه‌ی Sobel پردازش می‌کنه: خط‌ها و لبه‌های عکس سیاه و بقیه‌ی تصویر سفید می‌شه.

## اجرا

فقط فایل `index.html` رو در مرورگر باز کن (یا با یک وب‌سرور ساده مثل `python3 -m http.server` سرو کن).

## استفاده

1. روی «انتخاب عکس» بزن و یک فایل تصویری انتخاب کن.
2. با اسلایدر «حساسیت خط‌ها» تعیین کن چقدر لبه‌ی ظریف هم به‌عنوان خط در نظر گرفته بشه (عدد کمتر = خط‌های بیشتر).
3. با اسلایدر «ضخامت خط‌ها» می‌تونی خط‌های نتیجه رو کلفت‌تر کنی.
4. در صورت نیاز گزینه‌ی «معکوس کردن» رو بزن تا خط سفید روی زمینه‌ی سیاه بشه.
5. با دکمه‌ی «دانلود عکس نتیجه» خروجی رو به‌صورت PNG ذخیره کن.

همه‌ی پردازش‌ها داخل مرورگر خودت انجام می‌شه و هیچ عکسی به سروری فرستاده نمی‌شه.
