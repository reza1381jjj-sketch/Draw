# خط‌نگار

یک صفحه‌ی وب تک‌فایلی (بدون نیاز به سرور یا نصب چیزی) که عکس ورودی رو با الگوریتم تشخیص لبه‌ی Sobel پردازش می‌کنه: خط‌ها و لبه‌های عکس خاکستری و بقیه‌ی تصویر سفید می‌شه.

## اجرا

فقط فایل `index.html` رو در مرورگر باز کن (یا با یک وب‌سرور ساده مثل `python3 -m http.server` سرو کن).

## استفاده

1. روی ناحیه‌ی بزرگِ «اینجا کلیک کن تا عکستو انتخاب کنی» بزن (یا عکس رو بکش و رهاش کن) و یک فایل تصویری انتخاب کن.
2. با اسلایدر «حساسیت خط‌ها» تعیین کن چقدر لبه‌ی ظریف هم به‌عنوان خط در نظر گرفته بشه (عدد کمتر = خط‌های بیشتر).
3. با اسلایدر «ضخامت خط‌ها» می‌تونی خط‌های نتیجه رو کلفت‌تر کنی.
4. در صورت نیاز گزینه‌ی «معکوس» رو بزن تا خط سفید روی زمینه‌ی خاکستری بشه.
5. با دکمه‌ی «دانلود طرح خطی» خروجی رو به‌صورت PNG ذخیره کن.

صفحه هنگام باز شدن یک نمونه‌ی آماده نشون می‌ده تا قبل از آپلود عکس واقعیت هم ببینی چطور کار می‌کنه. همه‌ی پردازش‌ها داخل مرورگر خودت انجام می‌شه و هیچ عکسی به سروری فرستاده نمی‌شه.
